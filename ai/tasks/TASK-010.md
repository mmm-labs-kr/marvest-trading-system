# TASK-010: 불필요한 import 및 미사용 코드 제거

## 1. 목적
- 코드 베이스를 정리하여 가독성을 높이고 유지보수 비용을 절감.
- 사용하지 않는 라이브러리 임포트를 제거하여 시작 속도 및 메모리 사용량 미세 개선.

## 2. 상세 변경 사항

### 2.1 미사용 import 제거
- 각 파일 상단에서 선언되었으나 본문에서 사용되지 않는 모듈 제거.
- 예: `import sys`, `import re` 등 분석 과정에서 남겨진 잔재들.

### 2.2 중복 로직 및 미사용 함수 정리
- 이전 단계의 리팩토링으로 인해 더 이상 호출되지 않는 헬퍼 함수나 변수 제거.
- `trading.py` 및 `backtest.py` 등 주요 엔드포인트 집중 점검.

### 2.3 코드 스타일 통일
- 한 줄에 여러 모듈을 임포트하거나, 일관성 없는 임포트 순서 정리 (필요 시).

## 3. 작업 파일
- `backend/app/main.py`
- `backend/app/api/endpoints/*.py`
- `backend/app/core/*.py`

## 4. 테스트 계획
1. 모든 정리가 완료된 후 서버가 정상적으로 시작되는지 확인.
2. 각 API 엔드포인트가 여전히 의도한 대로 동작하는지 (임포트 제거로 인한 `NameError` 발생 여부) 확인.
